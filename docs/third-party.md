The variable WOFF2 provides weights 100–900 in one file. Its upstream Latin glyphs include Roboto. The font is served from the installed plugin and used only inside the Hamgoo administration page. The CSS family name is scoped to Hamgoo; the font binary and its internal name are unchanged. Unsupported glyphs use the operating system's fallback fonts.

When updating this asset, retain the upstream license and update the version, source commit and checksum here. Include both the font and its license in the installable ZIP.
