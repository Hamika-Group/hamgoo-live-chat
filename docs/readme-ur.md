## ضروریات اور سہولتیں

ورڈپریس **6.5+**، PHP **7.4+**، ہمکاران اکاؤنٹ اور فعال ہمگو ویجٹ، جس میں ویب سائٹ کا ڈومین اجازت یافتہ ہو۔ WooCommerce اختیاری ہے۔ پلگ ان مفت ہے؛ کلاؤڈ سروس کے لیے بامعاوضہ رکنیت درکار ہو سکتی ہے۔ صارف کی سائٹ پر Composer، Python یا Node.js ضروری نہیں۔

- صرف ویجٹ کلید سے رابطہ؛ پاس ورڈ یا نجی API ٹوکن درج نہ کریں۔
- فارسی، انگریزی، عربی، روسی اور اردو؛ پلگ ان کی الگ زبان اور RTL کی معاونت۔
- تمام یا منتخب صفحات؛ شائع شدہ صفحات/پوسٹس کی تلاش اور عوامی مواد کی اقسام۔
- ہوم، پوسٹس کی فہرست، آرکائیو، تلاش، 404 اور WooCommerce قواعد۔
- مکمل راستے یا wildcard؛ استثنا ہمیشہ دکھانے کے قواعد پر مقدم ہے۔
- موبائل/ڈیسک ٹاپ؛ براؤزر کی فرصت، تاخیر یا کلک کے بعد لوڈنگ۔
- رضامندی کے نظام سے رابطہ، رہنمائی، دستی ترتیب کی جانچ اور مجوزہ رازداری متن۔
- نیٹ ورک کی ہر سائٹ کی الگ ترتیبات اور حذف کرتے وقت اختیاری صفائی۔

## صفحات اور WooCommerce

تمام صفحات کا موڈ اہل عوامی صفحات پر چیٹ دکھاتا ہے۔ منتخب صفحات میں کم از کم ایک شرط پوری ہونی چاہیے؛ کوئی شرط منتخب نہ ہو تو چیٹ ہر جگہ چھپی رہتی ہے۔ دکھانے کی شرائط «یا» سے ملتی ہیں۔ **کوئی بھی استثنا چیٹ چھپا دیتا ہے۔**

ہر راستہ الگ سطر میں لکھیں؛ راستے ورڈپریس کے ہوم URL کے مطابق ہیں۔ query پیرامیٹر نظر انداز ہوتے ہیں۔ `/contact` آخری slash کے ساتھ یا بغیر ملتا ہے۔ `/services/*` ذیلی راستوں کے لیے ہے؛ اصل راستے کے لیے الگ `/services` لکھیں۔ `/*` تمام راستوں سے ملتا ہے۔

WooCommerce فعال ہو تو دکان، مصنوعات، مصنوعات کے آرکائیو، کارٹ، چیک آؤٹ اور اکاؤنٹ شامل یا مستثنیٰ کریں۔ خاص صفحات کے لیے صفحے یا راستے کا قاعدہ استعمال کریں۔ دوسرے قواعد WooCommerce کے بغیر بھی کام کرتے ہیں۔ انتظام، AJAX، REST، cron، feeds، embeds اور پیش منظر میں لوڈر شامل نہیں ہوتا۔

## لوڈنگ اور کارکردگی

فرصت کا موڈ صفحے کی تیاری اور براؤزر کی فرصت کا انتظار کرتا ہے۔ تاخیر کا موڈ صفحہ تیار ہونے کے بعد مقررہ وقت انتظار کرتا ہے۔ کلک کا موڈ مقامی بٹن پر کلک اور، جہاں ضروری ہو، رضامندی کے بعد سروس لوڈ کرتا ہے۔ اصل ویجٹ بٹن کی جگہ لیتا ہے؛ گفتگو خود کھلنے کا انحصار ہمگو کی ترتیب پر ہے۔

کیش سے مطابقت کے لیے آلہ براؤزر میں پہچانا جاتا ہے؛ 767 پکسل تک چوڑائی موبائل سمجھی جاتی ہے۔ پلگ ان صفحات اور لوڈنگ کنٹرول کرتا ہے، SEO میٹاڈیٹا تبدیل نہیں کرتا اور سرچ رینک یا کارکردگی اسکور کی ضمانت نہیں دیتا۔

## رضامندی اور بیرونی سروسز

کوکی مینیجر کی رضامندی کا انتظار فعال کریں اور ہر صفحے پر موجودہ رضامندی مینیجر جوڑیں۔ پلگ ان کوکی بینر نہیں بناتا اور رضامندی محفوظ نہیں کرتا۔

```js
// لوڈر چلنے سے پہلے اجازت:
window.HamgooLiveChatConsent = true;
// لوڈر چلنے کے بعد اجازت:
if (window.HamgooLiveChat) window.HamgooLiveChat.grantConsent();
// اجازت واپس لینا:
window.HamgooLiveChatConsent = false;
if (window.HamgooLiveChat) window.HamgooLiveChat.revokeConsent();
// چلتے ہوئے ویجٹ کو روکنے کے لیے اجازت کے بغیر صفحہ دوبارہ لوڈ کریں۔
// لوڈر چلنے کے بعد متبادل:
window.dispatchEvent(new CustomEvent('hamgoo:consent', {
  detail: { granted: true }
}));
```

اجازت صفحات کے استثنا یا آلے کی پابندی نہیں بدلتی۔ اجازت واپس لینا آئندہ لوڈنگ روکتا ہے؛ پہلے سے چلتے بیرونی کوڈ کو مکمل روکنے کے لیے بغیر اجازت صفحہ دوبارہ لوڈ کرنا ضروری ہے۔

شرط اور اجازت کے بعد `cp.hamkaran.cloud/widget/chat.js` حاصل ہوتا ہے۔ ویجٹ `api.hamkaran.cloud`، `cp.hamkaran.cloud` کے وسائل، `storage.s1.hamkaran.cloud` کی تصاویر/فائلیں، `js.pusher.com` اور مقررہ websocket استعمال کرتا ہے۔

درخواستوں سے IP اور براؤزر کی معمول کی معلومات ظاہر ہوتی ہیں۔ سروس صفحے کا URL/عنوان، حوالہ، براؤزر/سیشن اور وزیٹر کا نام، فون، ای میل، پیغامات، ٹائپنگ کی حالت، فائل اور آواز پراسیس کر سکتی ہے۔ localStorage/sessionStorage استعمال ہوتے ہیں؛ آواز ریکارڈ کرنے کے لیے مائیکروفون کی اجازت چاہیے۔ ورڈپریس صرف ترتیبات رکھتا ہے، کلاؤڈ گفتگو نہیں۔ انتظامی صفحہ کھولنے سے سروس کو خودکار درخواست نہیں جاتی۔

تفصیل: [بیرونی سروسز](../readme.txt)، [رازداری](https://hamkaran.cloud/privacy-policy/)، [سروس معاہدہ](https://hamkaran.cloud/%D8%AA%D9%88%D8%A7%D9%81%D9%82-%D9%86%D8%A7%D9%85%D9%87-%D8%A7%D9%85%D9%86%DB%8C%D8%AA%DB%8C/)۔

## ترقی اور ریلیز

PHP 7.4+، Composer، Python 3.9+ اور Node.js درکار ہیں۔ منصوبے کی جڑ سے:

```sh
composer install --no-interaction
composer lint
php tests/run.php
node --check assets/js/admin.js
node --check assets/js/loader.js
node tests/loader.test.js
python3 scripts/translations.py
git diff --exit-code -- languages
python3 scripts/verify.py
php scripts/preview.php
python3 scripts/package.py --tag v1.0.1
```

ترجمے کا ماخذ `languages/translations.json` ہے؛ PO/MO/POT بنتے ہیں اور نامکمل ترجمے پر جانچ ناکام ہوتی ہے۔ جامد پیش منظر `docs/*-preview.html` میں ہیں؛ اصل تلاش اور رابطے کے لیے ورڈپریس چاہیے۔

اختیاری جانچ: `wp eval-file tests/wordpress-smoke.php`، **صرف الگ عارضی ورڈپریس پر** فعال پلگ ان کے ساتھ۔ عارضی پوسٹس/ترتیبات بنتی ہیں؛ حقیقی یا صارف کی سائٹ پر نہ چلائیں۔
