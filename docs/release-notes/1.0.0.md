## همگو برای وردپرس — نسخه ۱٫۰٫۰

اتصال سایت وردپرسی به سرویس چت آنلاین همگو، با واردکردن کلید ویجت.

- پنل سرمه‌ای و آبی با فارسی، انگلیسی، عربی، روسی و اردو.
- قواعد صفحات، مسیرها، استثناها و ووکامرس.
- بارگذاری در زمان بیکاری مرورگر، با تأخیر یا پس از کلیک؛ کنترل دستگاه و رضایت.
- راهنمای نصب، حریم خصوصی، معرفی سرویس و پشتیبانی.

**برای نصب، فایل hamgoo-live-chat-1.0.0.zip را از Assets بگیرید.** فایل‌های Source code بسته نصب آماده نیستند. SHA256SUMS برای بررسی صحت دانلود همراه ZIP است.

[راهنمای فارسی](https://github.com/Hamika-Group/hamgoo-live-chat#readme) · [سرویس و مشاوره](https://hamkaran.cloud/) · [پنل و پشتیبانی](https://cp.hamkaran.cloud/)

افزونه رایگان است؛ چت به سرویس فعال همگو و کلید خودتان نیاز دارد. تصاویر فعلی موقت‌اند. ثبت در WordPress.org هنوز انجام نشده است.

## English

Initial release: widget-key connection, page and WooCommerce rules, three loading modes, device targeting, consent integration and five plugin languages.

Install the **hamgoo-live-chat-1.0.0.zip** asset. The plugin is free; an active Hamgoo cloud service and your own widget key are required. Artwork is provisional; WordPress.org publication is pending.
