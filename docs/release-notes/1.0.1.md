## همگو برای وردپرس — نسخه ۱٫۰٫۱

فونت وزیرمتن داخل خود افزونه قرار گرفت؛ متن‌ها، دکمه‌ها و فرم‌های پنل مدیریت همگو از فایل محلی آن استفاده می‌کنند. وزن‌های مختلف در یک فایل WOFF2 هستند و متن هنگام بارگذاری فونت نمایش داده می‌شود. مجوز فونت نیز همراه بسته است.

**برای نصب یا به‌روزرسانی، فایل hamgoo-live-chat-1.0.1.zip را از Assets بگیرید.** فایل SHA256SUMS برای بررسی صحت دانلود همراه آن است. پس از به‌روزرسانی، صفحه تنظیمات همگو را دوباره باز کنید.

## English

Locally bundled Vazirmatn improves Hamgoo administration text and form controls. A single variable WOFF2 supports weights 100–900, uses `font-display: swap`, and ships with its SIL Open Font License 1.1. Font loading requires no CDN.

Install or update using the **hamgoo-live-chat-1.0.1.zip** asset. SHA256SUMS is included for download verification.
